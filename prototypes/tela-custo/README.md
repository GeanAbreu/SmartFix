# Tela de custo

Este diretório preserva o componente de referência recebido como `Tela de Custo`.
Ele depende de TanStack Router, componentes de interface, assets e integração
Supabase que não acompanham o arquivo original; por isso não é executável de forma
isolada.

A implementação de produção deve ser adaptada às views do `smartfix-app`, seguindo
as camadas descritas em `smartfix-app/ARCHITECTURE.md`.
