# SmartFix - Painel Administrativo

## 📋 Sobre o Projeto

O SmartFix é uma plataforma voltada para o gerenciamento de serviços de assistência técnica.

Este projeto representa a interface do Painel Administrativo do sistema SmartFix, desenvolvido com foco no Requisito Funcional RF20.

O painel permite ao administrador visualizar informações relacionadas às Ordens de Serviço e realizar a mediação de conflitos entre clientes e assistências técnicas.

---

# 🎯 Requisito Funcional Atendido

## RF20 - Controle Central de Ordens de Serviço e Mediação

O sistema deve permitir que o administrador tenha uma visão global das Ordens de Serviço cadastradas na plataforma.

O administrador poderá:

- Visualizar todas as Ordens de Serviço;
- Filtrar OS por status;
- Filtrar OS por região;
- Buscar uma OS ou cliente;
- Visualizar conflitos relacionados aos serviços;
- Realizar a mediação entre cliente e assistência técnica;
- Registrar decisões administrativas.
