# SmartFix — Central de Ajuda e Chat

Tela do PWA SmartFix desenvolvida com:

- HTML5
- CSS3
- JavaScript puro

## Estrutura

```text
smartfix-central-ajuda/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Funcionalidades

- Central de perguntas frequentes.
- Pesquisa de dúvidas.
- Abrir e fechar respostas das FAQs.
- Identificação da assistência técnica designada.
- Chat entre cliente e assistência.
- Envio de mensagens.
- Envio usando Enter.
- Simulação de resposta da assistência.
- Seleção de anexos.
- Layout responsivo para desktop e celular.

## Como executar

Abra o arquivo `index.html` no navegador.

No VS Code, também pode ser utilizado o Live Server para facilitar o desenvolvimento.

## Observação

O chat atualmente é uma simulação no front-end. Para comunicação real entre cliente e assistência, posteriormente será necessário conectar o JavaScript a um back-end/API e, dependendo da arquitetura escolhida, WebSocket ou outro mecanismo de comunicação em tempo real.
